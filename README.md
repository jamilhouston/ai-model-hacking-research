# AI Model Hacking: When AI Goes Rogue

**CIS 8600 — Generative AI for Business | Academic group presentation**

A research presentation examining security and governance challenges associated with increasingly autonomous AI agents. The project explores how reward hacking, unexpected agent coordination, access to external systems, and prompt injection can create risks for organizations.

## Topics covered

- **Technical mechanisms:** evaluation boundaries, reward hacking, unintended communication channels, and access-control failures.
- **Prompt injection:** how untrusted content can manipulate an AI system's instructions or tool use.
- **Scale and coordination:** why multiple agents sharing discoveries can amplify risk.
- **Business implications:** third-party exposure, containment, monitoring, auditability, and human oversight.
- **Responsible deployment:** limiting permissions, testing controls, reviewing high-impact actions, and maintaining accountability.
